# Moodscape 🌈

Moodscape is a mood-based journaling web application that allows users to select their current mood and maintain personal journal entries.

## Features

- 😊 Mood selection
- 🎨 Dynamic mood-based interface
- 📝 Personal mood journal
- 📅 Mood tracking
- 👤 User authentication
- 🔐 Password protection
- 💾 Journal data storage
- 🖥️ Frontend and backend integration

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- JSON
- Git & GitHub
